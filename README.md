# Mon-Portfolio-Web
# 🎨 Web Design & Digital Presence

"Conception et déploiement d'une solution web optimisée pour une activité professionnelle. Ce projet combine design graphique et stratégie numérique pour répondre à un besoin métier concret."

## ✨ Points clés du projet
* **Design :** Création d'une identité visuelle cohérente avec **Canva**.
* **Développement :** Mise en ligne d'une interface fluide via **Wix**.
* **Performance :** Optimisation du **SEO** local et de l'expérience utilisateur (**UX**).
* **Adaptabilité :** Design 100% **Responsive** (mobile & tablette).
